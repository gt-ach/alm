Debt Navigator · UserTesting stimulus

Debt card & offer card — six variations, minimal → maximal

Same design system and canonical data as the North Star prototype (Jordan R.). Only information density changes between steps. Severity uses the prototype's triage palette throughout — red = costing you, amber = could improve, blue = already fine — and the color encoding deepens as the cards get denser.

Debt card — selectable

three canonical accounts, one per severity: Visa card (red) · Auto loan (amber) · Student loan (blue)
Every step shows all three severities so the color system reads at a glance. V1 is the colorless control; color enters at V2 and does more work at each step. Each card carries an include checkbox (unchecked by default), with a Select all checkbox per variation (dash = partial selection) — checked accounts get a subtle ring.

Set C — editorial large-type · debt cards + offer card

same canonical data · new visual language · body type up ~40%
A deliberate break from Sets A and B: severity moves from a thin left edge to a full-width color band with the verdict spelled out, the balance becomes a 42px hero number, and every spec field is a large labeled line instead of a tile or a dotted ledger row. Minimum readable size on the card is 12.5px (labels) against 8.5–9px in the tile set — built for over-the-shoulder and mobile-in-hand testing. The offer card keeps the quiet-link CTA and SmartFit Score, since those are offer identity rather than density.
